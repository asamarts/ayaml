## Why

Strings like `0644` are valid plain YAML 1.2, but older readers take them as
octal integers. Other forms are misread by YAML 1.1 readers too, and that is
undocumented.

## Acceptance criteria

- [x] strings that look like leading-zero numerals are quoted on all writer paths, including negative ones
- [x] `docs/compatibility.md` lists what YAML 1.1 readers still misread: `yes`, `no`, `on`, `off`, underscored numbers, sexagesimal values, dates, `=`, and `<<`
- [x] tests pin the output, and goldens change only where intended

## Why

`tools/check_instructions.py` currently measures instruction reads (`Ir`) only at
a +5% threshold on nine small inputs, missing cache and branch penalties as well
as domain workloads, typed structs, borrowed reads, spans, serialization, and
error paths. Running Callgrind with cache and branch simulation keeps zero extra
runner dependencies while providing steady-state `Ir` and `EstimatedCycles` gates
plus diagnostic cache and branch counters.

## Acceptance criteria

- [ ] the Callgrind probe uses `ayaml-fixtures` and runs with `--cache-sim=yes --branch-sim=yes`, reporting steady-state `Ir`, `EstimatedCycles`, and diagnostic cache/branch miss counters in structured JSONL and table form
- [ ] the PR gate compares base versus head with tighter limits (+2% `Ir` and +5% `EstimatedCycles`), preserving per-change allowances in `tools/instruction-rises.tsv`
- [ ] representative domain scenarios (including typed structs, borrowed reads, spans, emission, and late typed errors) are covered within CI time budgets
- [ ] `tools/test_ci_checks.py` verifies parsing, cycle computation, and threshold enforcement

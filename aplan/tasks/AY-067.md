## Why

Unit tests in `crates/ayaml/src/parser.rs` include fixtures from outside the crate's directory, and
those files aren't in the package. `cargo test` therefore doesn't compile in an unpacked crate,
which stops anyone packaging ayaml from running its tests. `cargo package` builds only the library,
so nothing notices.

## Acceptance criteria

- [ ] `cargo test --all-features --no-run` compiles from an unpacked `cargo package` tarball
- [ ] CI runs that check, so it stays true

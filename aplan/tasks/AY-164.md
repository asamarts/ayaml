## Why

The post-0.2.3 feature wave added `frontmatter.rs`, `merge/events.rs`, `typed/doc_de.rs`,
`Spanned<T>`, `from_reader*`, `LineStarts::line_start` cursor caching, and `ayaml-edit`, none
of which are exercised by the current `miri.yml` (`-p ayaml --lib`) or `kani.yml` harness sets.

- [x] bounded `miri.yml` coverage exercises `frontmatter`, `merge/events`, `DocumentDeserializer`, `Spanned<T>`, `from_reader`, and `ayaml-edit` (via unit tests or targeted integration tests) with zero UB or leaks
- [x] bounded `kani.yml` proofs (`python3 tools/run_kani.py`) verify pure arithmetic/slice-bound helpers for `frontmatter` delimiter scanning, `LineStarts::line_start` cursor caching, `prefix_token_capacity`, and `ayaml_edit::apply_edits` span-ordering/non-overlap invariants
- [x] both `miri.yml` and `kani.yml` pass cleanly on hosted CI

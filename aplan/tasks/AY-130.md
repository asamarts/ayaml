## Why

Existing property tests focus on scalar/value/Serde emission round trips and do
not yet verify key cross-layer invariants introduced across newer modules:
`SpannedTree` span integrity, `LineIndex` position bijectivity across encodings,
`Error::masked()` redaction guarantees, `Limits` monotonicity, and exact
equivalence between the small-tree and event-stream typed readers on both valid
and rejected inputs.

## Acceptance criteria

- [ ] property tests verify `from_str_by_tree` and `from_str_by_events` agree on both `Ok` values and `Err` kind, code, span, and location across structured valid and mutated YAML inputs
- [ ] property tests verify every `SpannedNode` span is in bounds, lies on UTF-8 character boundaries, nests inside its parent span, and matches `parse_documents` values
- [ ] property tests verify `LineIndex::offset(index.position(off, enc), enc) == Ok(off)` and monotonicity across UTF-8, UTF-16, and scalar columns with LF, CRLF, and BOM inputs
- [ ] property tests verify `Error::masked()` never leaks injected secret canary tokens across syntax, type, duplicate-key, and limit errors
- [ ] property tests verify `Limits` monotonicity (tightening a limit never turns an error into success; raising a limit never turns success into a limit error)

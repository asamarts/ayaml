## Why

Before tagging `1.0.0`, every public type, method signature, trait implementation
(`Send`, `Sync`, `Clone`, `PartialEq`, `Debug`, `std::error::Error`),
`#[non_exhaustive]` attribute, feature flag, error code, and deprecation must be
audited so no accidental break is locked into the 1.x series.

## Acceptance criteria

- [x] every public item across `ayaml` and `ayaml-edit` is reviewed against the 1.0 stability checklist
- [x] `docs/decisions.md` records the 1.0 API freeze sign-off and any final pre-1.0 cleanups
- [x] `docs/stability.md` reflects the 1.0 support, MSRV, and error-code stability guarantees

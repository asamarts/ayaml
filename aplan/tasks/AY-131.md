## Why

YAML 1.2.2 is specified as a strict superset of JSON (RFC 8259). Comparing
`ayaml` directly against `serde_json` on a comprehensive JSON conformance corpus
provides a zero-cost, independent oracle in CI covering flow collections, Unicode
escapes, surrogate pairs, number syntax, whitespace, and edge-case quoting.

## Acceptance criteria

- [ ] a deterministic RFC 8259 JSON conformance test suite runs in `cargo test` comparing `ayaml::parse_value` and `ayaml::from_str::<serde_json::Value>` against `serde_json::from_str`
- [ ] valid JSON inputs parse to identical values across `ayaml` and `serde_json`, including surrogate-pair escapes, extreme numbers, and nested flow structures
- [ ] any intentional YAML 1.2.2 versus JSON boundary case (such as duplicate keys or integer width) is explicitly documented and asserted

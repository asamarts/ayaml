## Why

Callers can only match broad error kinds or message text, and message text is not a
contract. The private codes from AY-027 can become a public list, in the same
`<format>.<kebab-name>` shape as adotenv's codes.

## Acceptance criteria

- [ ] `Error::code()` returns a non-exhaustive `ErrorCode`, and `as_str()` gives a stable `yaml.<kebab-name>` string
- [ ] every parser, composer, resolver, and Serde failure has a code, and a test pins each one
- [ ] a reference page lists each code and its meaning
- [ ] `Error` implements `Clone` and `PartialEq`
- [ ] `ErrorKind` stays available, and its relation to codes is documented

## Why

Callers can only match broad error kinds or message text, and message text is not a
contract. The private codes from AY-027 can become a public list, in the same
`<format>.<kebab-name>` shape as adotenv's codes.

## Acceptance criteria

- [x] `Error::code()` returns a non-exhaustive `ErrorCode`, and `as_str()` gives a stable `yaml.<kebab-name>` string
- [x] every parser, composer, resolver, and Serde failure has a code, and a test pins each one
- [x] a reference page lists each code and its meaning
- [x] `Error` implements `Clone` and `PartialEq`
- [x] `ErrorKind` stays available, and its relation to codes is documented

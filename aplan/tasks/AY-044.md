## Why

A few API gaps remain. `Mapping` iterators expose `indexmap` types, which ties
ayaml's API to that crate's major version, and `Entry` has no `Debug`. Entry points
without a limits form get one through the options values in AY-048, rather than through
new combination names.

## Acceptance criteria

- [ ] `Entry` implements `Debug`
- [ ] `Mapping` iterator newtypes are planned for the next minor version, with the semver impact stated
- [ ] `cargo-semver-checks` passes for everything shipped in a 0.1.x release

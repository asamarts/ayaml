## Why

Issue #178: a root flow collection grew its item or entry vector through doubling while the
whole token arena was still live. The final copy held both the old and new vectors at once.

## Acceptance criteria

- [x] the parser counts the top-level entries of a root flow collection from its matching tokens
- [x] the typed builder reserves the item or entry vector from that count before the start event
- [x] non-building sinks ignore the reservation
- [x] the 1 MB flow mapping falls from about 97 MB to 82 MB, the integer flow sequence from about 197 MB to 169 MB, and the flow sequence of `1` to about 98 MB
- [x] behavior, limits, and conformance are unchanged; both test modes pass

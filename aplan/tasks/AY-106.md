## Why

`tools/test_ci_checks.py` called `unittest.main()` before its last test class. CI runs the file
as a script, and that call exits, so 94 of its 99 tests ran and the tests of the scanner's
dependency policy never did.

## Acceptance criteria

- [x] the call that runs the tests is the last statement in the file, and all 99 tests run
- [x] a repository test fails if anything follows that call

## Why

Issue #163: typed source reads built one event vector per document, so its spare capacity and
reallocation lived beside the token arena and node tree.

## Acceptance criteria

- [x] typed source reads over 4 KiB consume events in fixed-size chunks
- [x] small typed reads keep the lower-overhead eager builder
- [x] the 1 MB nested typed peak falls to about 43.5 MB and the 11 MB one to about 392 MB, within 1.2x of the 376 MB libyaml reference
- [x] event order, limits, and eager event APIs are unchanged
- [x] the tiny typed instruction rise is recorded as an explicit allowance

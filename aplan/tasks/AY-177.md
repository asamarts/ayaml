## Why

`ayaml::parse_value` returns an owned, mutable `Value` tree (`Value::String(String)`), which
inherently requires one heap allocation per owned string scalar. High-throughput read-only
consumers (such as config indexers, query engines, and bulk document processors) benefit
dramatically from zero per-string allocations, minimal total allocations (2 to 5 per
document), and flat-array cache locality comparable to C++ arena parsers, while remaining 100%
safe Rust (`#![forbid(unsafe_code)]`) without mutating the input buffer.

Shipping `Tape<'a>` and `ParserBuf` in `1.0.0` gives callers a high-throughput safe-Rust
zero-copy path on day one, provided the public API is carefully designed and future-proofed
before the 1.0 SemVer freeze so internal storage, indexing, and optimization evolutions remain
non-breaking throughout the entire `1.x` series.

## Scope

1. **Pre-implementation API research & future-proofing design review (`docs/decisions.md`):**
   - Evaluate proven tape/arena/scratch API patterns (flat tape nodes, borrowed handles,
     lifetime ergonomics, error/limit parity, Serde integration, bulk buffer reuse) and record
     an explicit API design decision in `docs/decisions.md` before coding.
   - Enforce strict future-proofing invariants on every new public item:
     - All container, handle, scratch, and iterator types (`Tape<'a>`, `TapeRef<'_>`,
       `ParserBuf`, `TapeSeqIter<'_>`, `TapeMapIter<'_>`, etc.) are **100% opaque structs**
       with zero exposed internal node layout or `Vec` representation.
     - All new public enums and option structs carry `#[non_exhaustive]`.
     - No public method returns raw internal indices or commits to a fixed node byte size, so
       internal representation (compact node encoding, inline string tables, optional index
       acceleration) can evolve freely in `1.x`.
     - Explicit trait freeze assertions (`Send`, `Sync`, `Unpin`, `Debug`, `Clone` where
       sound) pinned in `crates/ayaml/tests/api_freeze.rs`.
2. **Read-only flat-array `Tape<'a>` DOM (`crates/ayaml/src/tape.rs`):**
   - Store parsed nodes in a single contiguous flat node vector (compact 16-byte internal
     nodes with `u32` offsets/lengths into `&'a str` or a single decoded-string bump `String`,
     plus `u32` child/sibling links) with zero per-node heap allocations and zero `unsafe`.
   - Provide clean read-only navigation (`TapeRef<'_>`, mapping/sequence iteration, key lookup,
     typed scalar resolution, source spans, conversion to `Value`) and a
     `serde::Deserializer<'a>` implementation.
   - Enforce all `Limits` (depth, events, alias expansion, duplicate keys, scalar bytes) and
     `Error::masked()` semantics identically to `parse_value`.
3. **Reusable scratch buffer `ParserBuf`:**
   - Expose an opaque `ParserBuf` holding reusable internal parser, scanner, and seen-key
     buffers so bulk loops (`parse_value_in`, `from_str_in`, `parse_tape_in`, etc.) incur zero
     internal parser allocations across repeated calls, with explicit capacity-bound hygiene
     (`clear` / `shrink_to` or bounded retention) to prevent unbounded memory retention after
     an outlier document.
4. **Thorough verification and benchmarks:**
   - Add YAML Test Suite conformance, RFC 8259 JSON oracle, `proptest` equivalence against
     `parse_value`, `in_child!` adversarial DoS tests, Miri, Kani (pure index/offset helpers),
     fuzz target integration, `ayaml-bench` throughput/bulk benchmarks, and `memcount` memory
     coverage.

## Acceptance criteria

## Why

Random fuzzing and unit tests can miss rare 64-bit integer overflow boundaries,
UTF-8 slicing edge cases, or number equality/hashing corner cases. Pointing Kani
bounded model checking strictly at small, pure, loop-bounded kernels yields
exhaustive symbolic proofs with low maintenance overhead.

## Acceptance criteria

- [ ] `#[cfg(kani)]` proof harnesses verify `Limits` and `AliasBudget` arithmetic overflow freedom, `LineIndex` UTF-8/UTF-16/scalar offset math, `Number` conversion/equality/hash coherence, `Span` invariants, and `Error` path-truncation UTF-8 boundary safety
- [ ] all five Kani proof groups verify cleanly with zero assertion or unwinding failures
- [ ] a scheduled workflow runs the Kani proof suite on hosted runners
- [ ] companion unit tests run the corresponding boundary checks under standard `cargo test`

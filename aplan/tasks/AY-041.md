## Why

The scanner is meant to use only `core`, `alloc`, and `std` plus crate-local modules.
Nothing enforces it.

## Acceptance criteria

- [x] a test or policy check fails if the scanner uses anything beyond `core`, `alloc`, `std`, and approved crate-local modules
- [x] a deliberate violation proves the check fails
- [x] `docs/dependencies.md` states the rule

## Verification

The import boundary is a Python policy check, so it is verified by `tools/test_ci_checks.py`'s
`ScannerDependencyPolicy` tests and by the `python3 tools/check_deps.py` CI step rather than by
the repository's Cargo test runner.

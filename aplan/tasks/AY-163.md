## Why

`ayaml-edit` is marked `Stable (additive)` for `1.0`, but `.github/workflows/release.yml`,
`tools/check_release.py`, `cargo-semver-checks`, `tools/check_public_api.py`, `cargo-geiger`,
and the strict panic-profile Clippy step currently cover `ayaml` alone, and `RELEASING.md`
still notes a manual workstation publish path for `ayaml-edit`.

## Acceptance criteria

- [ ] `.github/workflows/ci.yml` runs the strict panic-profile Clippy check, `cargo-geiger`, packaging smoke, docs lint (`crates/ayaml-edit/README.md`), and `cargo-semver-checks` / public API checks for `ayaml-edit` alongside `ayaml`
- [ ] `.github/workflows/release.yml` and `tools/check_release.py` package, verify, attest, and publish `ayaml-edit` via crates.io Trusted Publishing after `ayaml` is live on the sparse index, removing any manual workstation publish instruction from `RELEASING.md`
- [ ] `tools/test_ci_checks.py` verifies the multi-crate release packaging and verification paths

## Why

The plain-scalar fast path added in 0.1.1 rejects some multi-line plain scalars
that 0.1.0 accepts, and the corpus comparison did not catch it.

- [x] a property test compares the fast path with the full path over generated scalars
- [x] the performance gates still pass
- [x] the changelog names the regression

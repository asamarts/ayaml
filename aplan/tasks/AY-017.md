## Why

The plain-scalar fast path added in 0.1.1 rejects some multi-line plain scalars
that 0.1.0 accepts, and the corpus comparison did not catch it.

## Acceptance criteria

- [ ] multi-line plain scalars after whitespace-only lines, and after property-led keys, parse as in 0.1.0 and the spec
- [ ] a property test compares the fast path with the full path over generated scalars
- [ ] the performance gates still pass
- [ ] the changelog names the regression

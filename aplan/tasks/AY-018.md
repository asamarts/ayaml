## Why

Several writer paths produce output that reads back differently from what was
written, or truncate silently.

## Acceptance criteria

- [ ] multi-document output with explicit document starts round-trips with the same number of documents
- [ ] tags with percent escapes keep their identity through write and reread
- [ ] long non-string implicit keys are written in a form that can be read back
- [ ] duplicate keys from flattened Serde structs are an error, not silently dropped
- [ ] a failing key `Display` returns an error rather than truncated output
- [ ] round-trip tests cover each case on every writer path

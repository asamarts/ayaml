## Why

Several writer paths produce output that reads back differently from what was
written, or truncate silently.

## Acceptance criteria

- [x] multi-document output with explicit document starts round-trips with the same number of documents, which `every_document_reads_back_once_whatever_markers_the_writer_adds` and, for the event writer, `the_event_writer_keeps_each_document_apart` check
- [x] tags with percent escapes keep their identity through write and reread, as `!e!a%20b` under `%TAG !e! tag:x:` doesn't from the value writer, and so does any tag that a verbatim tag can't hold, such as one from a `%TAG` prefix without a scheme, so that AY-025 can refuse verbatim tags that aren't tag names. The writers add a `%TAG` directive for such a tag (D82), which `a_tag_with_a_percent_escape_keeps_its_name`, `a_tag_from_a_prefix_without_a_scheme_keeps_its_name`, `a_built_tag_that_no_verbatim_tag_can_hold_reads_back`, `several_documents_each_declare_the_tags_they_use` and `a_streamed_document_declares_its_tags_after_earlier_documents_are_written` check, `each_tag_takes_the_first_form_that_reads_back` and `every_tag_of_a_mapping_is_declared_before_it` check the forms written, the writers' look for such tags stops where they do, which `the_look_for_directives_stops_where_the_writer_does` checks, and a tag with no form is an error, which `a_tag_that_yaml_cannot_hold_is_an_error` checks
- [x] long non-string implicit keys are written in a form that can be read back, which `a_tagged_key_too_long_to_be_implicit_reads_back` and `a_flow_key_takes_the_explicit_form_past_128_characters` check
- [x] duplicate keys from flattened Serde structs are an error, not silently dropped, which `a_key_that_a_flattened_struct_repeats_is_an_error` and `a_key_that_a_map_repeats_is_an_error` check
- [x] a failing key `Display` returns an error rather than truncated output, which `a_display_that_fails_is_an_error_not_a_prefix` checks
- [x] round-trip tests cover each case on every writer path: the value writer, the Serde writer, and the event writer, collected and streamed, to a string and to an `io::Write`

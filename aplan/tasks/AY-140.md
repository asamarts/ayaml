## Why

Performance workflows are currently split across shell and Python scripts with
different CLI conventions and output formats. A single workspace `xtask` crate
provides reproducible local and CI orchestration for fixture manifests, Criterion
runs, JSONL memory measurements, steady-state Callgrind checks, automated linear
scaling checks, baseline-to-head comparisons, and Markdown summary rendering.

## Acceptance criteria

- [ ] `cargo xtask` implements `fixtures`, `speed`, `memory`, `det`, `scale` (verifying linear time and memory growth across 10x input sizes), `compare`, `gate`, and `report`
- [ ] runs emit schema-validated JSONL results and sibling hardware/toolchain fingerprint metadata
- [ ] `docs/benchmarks.md` documents how to reproduce every measurement locally without naming private infrastructure or external comparison targets
- [ ] unit tests cover JSONL schema validation, scaling-ratio checks, comparison diffs, and gating logic

## Why

Hand mutation found that more than half of 51 mutants survived. adotenv already runs
cargo-mutants on a schedule. Limit-disabling mutants can turn adversarial tests into
real memory bombs, so this must be bounded.

## Acceptance criteria

- [x] `cargo-mutants` runs on a schedule on hosted runners, never on a shared host
- [x] limit-disabling mutants are excluded, or every mutant run has a hard memory and process-group bound
- [x] surviving mutants are triaged, and spans, positions, and indentation options get targeted tests
- [x] a results trend is reviewable, with a documented way to accept or fix survivors

## Qualification status — 2026-11-14

Both consumer qualification branches have been updated, and their local matrices now pass against
the 0.1.2 candidate. The linter side still needs its `det_check` environment and its
differential-fuzzing gate; the planning side retains its documented cutover gates. The candidate
is prepared for release in PR #114, but no 0.1.2 tag or publication exists yet. The release remains
blocked until the tag workflow and the consumer requalification against the published crate both
complete. These are consumer-side gates and documented intentional-change updates, not reasons to
weaken ayaml's behavior.

## Why

The fixes reach consumers only as one immutable release, whose local, hosted, conformance,
hostile-input, performance, package, and provenance evidence all name the same public source
revision.

## Acceptance criteria

- [ ] Rust 1.88/stable quality, all tests/docs, strict conformance, adversarial, property, fuzz, corpus, package, semver, dependency, and unsafe gates pass
- [ ] quiet-host parser, default and compat typed parsing, emitter, allocation, peak-heap, and short-block gates pass on numbers re-measured from the release candidate, and the runner fails on any breach
- [ ] the pre-release comparison gates run clean against the release commit before tagging
- [ ] `tools/ci-local.sh --release` passes on the release commit, with no check skipped
- [ ] each consumer requalifies against the release candidate, including `from_value` config paths
- [ ] the changelog states every newly rejected input and behavior change
- [ ] Linux, macOS, Windows, cross-target, minimal-version, secret-scan, and package-smoke jobs pass on the tag commit
- [ ] 0.1.2 is published, indexed, documented, checksummed, released, and attested from the trusted workflow
- [ ] the release record gives consumers immutable identifiers and exact verification commands
- [ ] property tests run at the release case count, and the fuzz workflow runs on the release commit
- [ ] the package holds both licenses, the notice, the readme, the changelog, and repository metadata
- [ ] 0.1.1 stays published and isn't yanked merely because a patch exists

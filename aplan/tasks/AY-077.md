## Why

The adoption change has to carry temporary per-file ratchets so it can merge green. Once the five
oversized files are split, the repository should have one simple invariant rather than permanent
exceptions that future files can imitate.

## Acceptance criteria

- [ ] the 2,000-line rule covers every maintained Rust, Python, shell, and hook source file, with no path exclusion, baseline entry, or temporary ratchet
- [ ] every covered file passes the full-tree rule
- [ ] a throwaway boundary smoke proves that a 2,000-line source passes and a 2,001-line source fails, that each covered language is matched, and that a Rust file outside today's `crates/`, `fuzz/`, and `tools/` directories is still covered
- [ ] full-tree `alint check --fail-on-warning` passes locally with alint 0.22.0

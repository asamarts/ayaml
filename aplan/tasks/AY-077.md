## Why

The adoption change has to carry temporary per-file ratchets so it can merge green. Once the five
oversized files are split, the repository should have one simple invariant rather than permanent
exceptions that future files can imitate.

## Acceptance criteria

- [ ] the 2,000-line rule covers every maintained `.rs`, `.py`, `.sh`, and `.bash` file plus `tools/hooks/*`, with no path exclusion, baseline entry, or temporary ratchet
- [ ] every covered file passes the full-tree rule
- [ ] final throwaway boundary probes repeat that 2,000 lines pass and 2,001 lines fail for every covered extension, the extensionless hook, and a Rust source outside today's `crates/`, `fuzz/`, and `tools/` directories
- [ ] full-tree `alint check --fail-on-warning` passes locally with alint 0.22.0

## Why

Today only owned `Value` implements `serde::Deserializer`, while
`ayaml::Deserializer` is a multi-document cursor. Callers using Serde middleware
wrappers that track field paths or collect unknown keys cannot wrap `ayaml`'s
fast, borrowed, span-preserving source deserializer without first composing a
full `Value` and losing YAML source spans.

## Acceptance criteria

- [ ] a public source-backed single-document deserializer entry point (such as a scoped callback or `DocumentDeserializer` implementing `serde::Deserializer`) exposes the borrowed, span-preserving typed reader to arbitrary Serde wrapper deserializers
- [ ] explicit-limits and compatibility variants follow the crate's established naming and options conventions
- [ ] integration tests prove path-tracking and unknown-field-collecting Serde wrappers work directly over YAML source while preserving YAML error spans and resource limits

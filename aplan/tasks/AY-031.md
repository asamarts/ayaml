## Why

A limit regression would make the alias-bomb test exhaust the machine instead of
failing. The local gate also runs these tests with no memory bound.

## Acceptance criteria

- [ ] hostile-input tests run in a child process under an address-space limit, with no new `unsafe`, and a limit regression fails the test
- [ ] a deliberately oversized allocation in that child fails quickly and cleanly, proven by a test that never disables a real limit
- [ ] `tools/ci-local.sh` runs test steps under a memory ceiling and a timeout that kills the process group
- [ ] the ceiling is documented, and normal runs stay well below it

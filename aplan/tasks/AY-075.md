## Why

`emitter.rs` is 2,338 lines and mixes public entry points, scalar/style selection, the writing
engine, and unit tests. A small responsibility split closes the size violation before more output
correctness work lands.

## Acceptance criteria

- [ ] emitter code is split by responsibility into ordinary Rust modules; `include!` and generated concatenation are not used to evade the line rule
- [ ] every resulting file is at most 2,000 lines, and the emitter exclusion and temporary ratchet leave `.alint.yml`
- [ ] public paths and private visibility stay unchanged unless a private path narrows
- [ ] every value, Serde, writer, and round-trip test observes identical bytes and errors before and after the split
- [ ] output allocation and instruction gates show no regression attributable to the split, and no new allocation, copy, dynamic dispatch, or repeated computation is introduced

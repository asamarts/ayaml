## Why

Invalid forms parse without error. These rejections are bug fixes, stated in the
changelog. Each applies in default and compat mode unless a criterion says otherwise.

## Acceptance criteria

- [ ] block collections on a `---` line that the grammar forbids are rejected on every entry point, including the streamed one, and the narrow skip in `fuzz/fuzz_targets/borrowed.rs` goes away
- [ ] repeated, contradictory, or out-of-range block scalar indicators, and whitespace before an indicator, are rejected
- [ ] empty verbatim tags, empty `!!` tags, a named handle with no suffix, and a verbatim `!` are rejected
- [ ] a `%` in a verbatim tag without two hex digits after it is rejected
- [ ] a document marker line inside a multi-line plain scalar in a flow collection is rejected
- [ ] a tab before a block sequence entry or an explicit mapping key, at the start of a line or after another such indicator or a `:` indicator, is rejected, whichever separator follows the indicator
- [ ] a flow `?` directly followed by a flow indicator is rejected; compat keeps its existing reading of `?` before other text
- [ ] duplicate `%TAG` handles in one document are rejected
- [ ] multi-line quoted scalars respect the indent check
- [ ] a plain scalar's continuation lines in a flow collection under a block collection respect the indent check, by default
- [ ] flow and quoted lines under nested block collections are measured against the innermost collection, by default
- [ ] a quoted scalar's line under a block collection isn't exempt from the indent check because it starts with the other kind of quote
- [ ] a tab alone doesn't indent a block node under a key or indicator, nor a plain scalar's line in a flow collection under a block collection, in compat too
- [ ] a byte order mark in a comment after a block scalar header is rejected
- [ ] in compat too, a flow key's `:` on a line not indented past the block collection around it is rejected
- [ ] a verbatim tag that isn't a valid global or local tag name is rejected, as in the specification's example 6.25
- [ ] enum variant selection ignores foreign-handle tags and mapping forms it should not accept
- [ ] each change is stated in the changelog, with suite classifications unchanged or justified

## Why

Invalid forms parse without error. These rejections are bug fixes, stated in the
changelog.

## Acceptance criteria

- [ ] block collections on a `---` line that the grammar forbids are rejected on every entry point, including the streamed one, and the narrow skip in `fuzz/fuzz_targets/borrowed.rs` goes away
- [ ] repeated, contradictory, or out-of-range block scalar indicators, and whitespace before an indicator, are rejected
- [ ] empty verbatim tags and empty `!!` tags are rejected
- [ ] a `%` in a verbatim tag without two hex digits after it is rejected
- [ ] a document marker line inside a multi-line plain scalar in a flow collection is rejected
- [ ] a flow `?` without separation after it, such as `[?]`, is rejected
- [ ] duplicate `%TAG` handles in one document are rejected
- [ ] multi-line quoted scalars respect the indent check
- [ ] enum variant selection ignores foreign-handle tags and mapping forms it should not accept
- [ ] each change is stated in the changelog, with suite classifications unchanged or justified

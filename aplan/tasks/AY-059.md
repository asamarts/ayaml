## Why

An alias inside a node can resolve to an earlier node that has the same anchor as the node
that encloses it. YAML says an alias refers to the most recent preceding node with its
anchor, so this reads a wrong value with no error, in both modes.

## Acceptance criteria

- [x] an alias inside a node that carries the same anchor is rejected the same way, whether or not an earlier node has that anchor
- [x] redefining an anchor in sibling nodes keeps working
- [x] the alias budget and existing alias tests are unchanged
- [x] the changelog names the changed behavior

## Why

Compatibility mode exposes only an eager Vec event reader. A consumer that needs spans or early errors must hold the whole stream and cannot stop early.

## Acceptance criteria

- [x] compat::parse_events and a with-limits form return the same pull-shaped EventStream as default mode
- [x] errors are yielded as items and alias checking behavior matches the compatibility reader
- [x] the eager Vec form stays available for the conformance runner

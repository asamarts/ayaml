## Why

Deterministic Valgrind DHAT and Callgrind profiling pinpointed four high-impact, zero-API-break
sources of peak heap, allocation churn, and CPU overhead:

1. **`Box<ScalarToken>` on every unescaped quoted scalar (`scanner/scalars.rs`):** Single-line
   unescaped double- and single-quoted scalars currently allocate a 32-byte `Box<ScalarToken>`
   wrapping `Cow::Borrowed`, causing 81% to 94% of the excess allocation count on
   `boundary-4kb-*` (`173` to `188` allocs), `2,400` extra allocs on `json-in-yaml`, `1,044` on
   `lockfile-wide`, `1,182` on `unicode-multibyte`, and `6,300` on `scale-openapi-1mb`.
2. **72-byte `Value` and dual-allocated `IndexMap` on small mappings (`mapping.rs`, `composer.rs`):**
   `Mapping` stores `IndexMap<Value, Value, GlobalHasher>` (56 B) plus `OnceLock<u64>` (16 B)
   inline inside `enum Value`, making every `Value` 72 B and every `IndexMap` bucket 152 B. In
   addition, every 1-to-8-entry mapping allocates both `hashbrown::RawTable` and `Vec<Bucket>`
   (2+ allocations and SipHash per tiny map), and `StreamingComposer` never shrinks collections.
3. **Double hashing, alias path cloning, and token-arena chunk bug (`composer.rs`, `parser.rs`):**
   `StreamingComposer::feed` calls `contains_key` followed by `insert` (hashing every key twice
   instead of calling `insert_new`), clones `AnchorDef` (`Vec<Step>`) on every alias reference
   (`+993` allocs on `aliases-1000`), computes `estimate_size`/`value_height` even with zero
   anchors, and `read_lines` selects `TOKEN_ARENA_CHUNK` (256 KiB) instead of
   `TOKEN_ARENA_SMALL_CHUNK` (2 KiB) on `large-scalar-1mb`.
4. **Redundant scalar copies and double plain resolution (`parser/grammar.rs`, `resolver.rs`, `typed.rs`):**
   Escaped and block scalars are cloned out of `token_arena`, re-copied by `resolve_scalar`,
   and re-copied again in `NodeDeserializer` (`visit_str` instead of `visit_string`), while
   `typed::scalar_node` runs `resolve_plain` twice per non-string scalar and `borrowed_or_owned`
   runs byte-by-byte comparison on already-borrowed `Cow::Borrowed` slices.

## Scope

1. **Zero-allocation unit `TokenKind` variants for unescaped quoted scalars (`scanner.rs`, `scanner/scalars.rs`):**
   - Add unit variants `TokenKind::SingleQuotedScalar` and `TokenKind::DoubleQuotedScalar`
     whose slice is `&input[span.start + 1 .. span.end - 1]` (zero heap allocations and zero
     `TokenKind` size growth).
2. **Compact `Mapping` (`Value` 72 B -> 32 B) with linear small-map storage (`mapping.rs`, `composer.rs`, `number.rs`):**
   - Represent `Mapping`'s private interior as an enum (`Empty`, `Small(Box<[(Value, Value)]>)`
     for `<= 8` entries with linear scan and zero `RawTable`/hashing, `Large(Box<LargeMapping>)`
     using `IndexMap` + `AtomicU64` cached hash) so `size_of::<Value>() == 32` B and `Mapping::new()`
     is allocation-free with zero public API changes.
   - Build mappings and sequences in `StreamingComposer` via reusable scratch buffers
     (`scratch_entries` / `scratch_items`) or exact-sized reservation and trim oversized buffers
     so live and peak heap eliminate 2x reallocation slack.
3. **Composer and token-arena hot-path fixes (`composer.rs`, `parser.rs`, `lib.rs`):**
   - Replace `contains_key` + `insert` in `StreamingComposer::feed` with single-probe
     `mapping.insert_new`.
   - Split-borrow `self.anchors` instead of `.cloned()` on alias resolution; skip
     `estimate_size`/`value_height` when `anchors` is empty; avoid single-element `Vec<Value>`
     wrapping in `parse_value`.
   - Fix `read_lines` to select `TOKEN_ARENA_SMALL_CHUNK` on long-line inputs (`large-scalar-1mb`).
4. **Eliminate redundant scalar clones and double resolution (`parser/grammar.rs`, `resolver.rs`, `typed.rs`, `typed/node_de.rs`, `typed/key_text.rs`):**
   - Move `Cow::Owned` scalars out of tokens when consuming owned token storage, add
     `resolve_scalar_cow`, fast-path `Cow::Borrowed` in `borrowed_or_owned`, resolve plain
     scalars once in `scalar_node`, call `visit_string` for `Cow::Owned` in `NodeDeserializer`,
     and return `Cow::Borrowed("true"/"false")` in `key_text.rs`.

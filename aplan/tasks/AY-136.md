## Why

Benchmark, allocation, and instruction probes currently duplicate synthetic input
generators and cover only a narrow set of shapes. A single internal fixture crate
with fixed PRNG seeds and SHA-256 hashes guarantees every benchmark, memory, and
Callgrind check measures identical inputs across realistic YAML domains.

## Acceptance criteria

- [x] `crates/ayaml-fixtures` generates deterministic fixtures across realistic domains (multi-document cluster manifests, large OpenAPI specs, CI workflows with block scripts, container specs with anchors and merges, bulk small automation files, wide lockfile mappings, custom-tag templates, escape-heavy route configs, tiny frontmatter headers, JSON-in-YAML payloads, and multi-byte Unicode) plus boundary and scaling shapes
- [x] every generated fixture carries a deterministic SHA-256 digest and manifest check
- [x] unit tests verify fixture reproducibility, SHA-256 stability, and valid parsing across the catalog

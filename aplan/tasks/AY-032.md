## Why

Strict conformance exits 0 with zero cases when the suite is missing.
`AYAML_STRICT_SUITE=0` still means strict, and `AYAML_BLESS=0` still blesses. The
suite's pinned revision hash is never checked.

## Acceptance criteria

- [x] strict mode fails unless the expected fixture and case counts are present
- [x] the suite tree hash is verified against its recorded revision
- [x] environment flags accept only documented values and reject anything else
- [x] an unparsable allocator threshold fails rather than silently disabling its gate
- [x] each failure mode has a test

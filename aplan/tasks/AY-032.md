## Why

Strict conformance exits 0 with zero cases when the suite is missing.
`AYAML_STRICT_SUITE=0` still means strict, and `AYAML_BLESS=0` still blesses. The
suite's pinned revision hash is never checked.

## Acceptance criteria

- [ ] strict mode fails unless the expected fixture and case counts are present
- [ ] the suite tree hash is verified against its recorded revision
- [ ] environment flags accept only documented values and reject anything else
- [ ] an unparsable allocator threshold fails rather than silently disabling its gate
- [ ] each failure mode has a test

## Why

`fuzz/src/bin/memcount.rs` currently prints ad-hoc key-value lines and checks
positional numeric budgets passed from shell scripts. Recording structured JSONL
rows with fixture SHA-256 digests and gating against a committed JSONL baseline
gives reproducible, schema-validated tracking across peak bytes, live bytes,
allocation counts, and total allocated bytes.

## Acceptance criteria

- [x] `memcount` consumes `ayaml-fixtures` and emits structured JSONL rows recording scenario, size, fixture SHA-256, operation, peak bytes, live bytes, allocation count, total allocated bytes, and peak-to-input ratio
- [x] measurement modes cover value composition, typed struct/value decoding, borrowed decoding, untyped JSON decoding, `SpannedTree`, value emission, and Serde serialization
- [x] CI gates allocation metrics against a committed baseline JSONL with clear per-metric regression diagnostics and unit tests for the gate parser

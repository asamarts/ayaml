## Why

The event writer can return success on input that does not produce valid YAML, and
empty collections are not charged for depth by the value writer.

## Acceptance criteria

- [ ] undefined and forward aliases are errors
- [ ] invalid `%YAML` values, duplicate directives, and bad tag handles are errors
- [ ] hand-built tags that cannot carry their payload are errors
- [ ] the value writer, event writer, and parser agree on depth for empty collections

## Why

Mutation checks showed that writer output above 8 KiB and the key order of typed
mappings are not compared by any gate, so dropped output or reordered keys could
pass everything.

## Acceptance criteria

- [ ] writer tests compare complete output above the internal chunk size, on every writer path
- [ ] typed mapping key order is asserted against source order
- [ ] mutants that drop chunks or reorder keys fail these tests

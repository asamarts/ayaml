## Why

Adopters evaluating `ayaml` for 1.0 need transparent, reproducible performance
and memory data across Tier 1 event parsing, Tier 2 semantic DOM composition,
owned/borrowed typed Serde decoding, YAML emission, 10x linear scaling, and
peak heap — alongside clear methodology and architectural trade-offs.

## Acceptance criteria

- [x] a dedicated `/benchmarks/` page renders structured charts and tables from pinned JSON/JSONL benchmark artifacts (throughput, latency, peak heap, allocations, and 10x scaling)
- [x] methodology, hardware/compiler provenance, local reproduction commands (`cargo xtask`, Callgrind, allocation gates), and safety/conformance trade-offs are documented clearly
- [x] all benchmark links, data integrity checks, and site builds pass in CI

## Why

The current mdBook site serves the technical reference well, but a 1.0 release
benefits from a modern, approachable landing page, responsive Starlight docs
navigation, dark/light theme polish, fast client-side search, and `llms.txt`
output while keeping `docs/` as the single source of truth for workspace
`book_doctests`.

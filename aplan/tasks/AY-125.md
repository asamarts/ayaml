## Why

Independent reviews of the third audit's fixes (AY-117) and of `Mapping`'s iterator types
(AY-120) found a loop over a mapping costing a caller twice what it cost before the types,
tests that passed with what they guard taken out, a compatibility reading that still depended
on how many byte-order marks opened the stream, a reader that gave out a value after a
mapping's end where the other refused, and figures in the docs that a measurement didn't bear
out.

## Acceptance criteria

- [x] a loop over a mapping from another crate executes what it did before the iterator types: their methods are inlined into the caller, and `collect` is handed on; `iter` and `iter_mut` return the named types
- [x] the instruction gate counts a walk over a value's mappings from its own crate, so a loop that costs a caller more shows there, and a key nested in keys, so a cache taken out shows on any host
- [x] the test that keeps the map's crate out of the API lists each line that may name it, and fails for a signature on a later line, a renamed import, a re-export, an alias, and a public field, each of which it is run on
- [x] the iterator types are held to the variance, the panic safety, the pinning, and the printing of the types they replace, and every way to change a mapping is shown to forget its cached hash
- [x] the version test finds every statement of the release and every install line of a document, and reads the supported series in `SECURITY.md`; a policy test fails outside the repository unless it runs from the published package
- [x] the two steps that the policy tests require of CI are refused with a shell, a directory, a condition, or compiler flags that would keep them from running what they name, each on a changed copy of the workflow
- [x] the allocation gate's tests see every argument of every measurement and a failure in each file; 17 single changes to the gate fail them, where 9 of 29 did; the typed peak budget is 1.10 times the measured value, and fails with the room given back by `Value` taken out
- [x] in compatibility mode a comment after a run of marks at the start, with a plain scalar of several lines after it, reads as after one mark, which every short text is tried for; a second mark on a later line is text, as libyaml reads it
- [x] a pair of a flow sequence doesn't end with a mark that begins a line, a leading run of marks takes no entry span away, and a key that holds a merge key makes its mapping's lookups a guess, which the rustdoc says
- [x] a visitor that asks a mapping for a value after its end is refused by every reader in the same words; a collection tells no size after a fault; an input of exactly 4 KiB is read from a tree
- [x] the changelog names what a caller of 0.1.3 can notice that it left out: an error's kind, a compatibility value after a run of marks, the room a typed target keeps, the methods the old iterator types had, and when the lazy compatibility stream reports another problem than the vector
- [x] the docs give the figures that were measured: what the events cost a tiny document and a document of one-item collections, what a node that is built whole costs inside a document, and what a slot of a mapping's set of keys takes
- [x] what is left is filed: a key that is a collection is copied at every level (AY-123), the semver check saw none of the four breaks (AY-124), and the tasks of the interface and of global tags say what the code does

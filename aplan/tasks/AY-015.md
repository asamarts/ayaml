## Why

Tag prefixes are re-expanded per use with no limit on the total. A node cost of
zero is accepted, which disables the alias budget, although the docs say limits
fail closed. Block-scalar and arena peaks also deserve a stated bound.

## Acceptance criteria

- [ ] total tag expansion is bounded, with a structured limit error
- [ ] settings that would disable a budget are rejected
- [ ] block-scalar and arena peak memory is measured and bounded relative to input
- [ ] each bound has tests below, at, and above it, under a memory cap

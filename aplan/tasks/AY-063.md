## Why

An audit of AY-031 found ways to get past its bounds. Only the parent enforced a child's
deadline, a test could name another test and pass without running its body, a child's output
could grow the parent, and `tools/ci-local.sh` stopped passing Ctrl-C on to a test step.

## Acceptance criteria

- [x] a child ends itself at its own deadline, so it can't outlive a test binary that died
- [x] each test in `adversarial.rs` that reads YAML runs in a child, and a test can't name another test and pass without running its body
- [x] a child's output can't grow its parent past a fixed amount
- [x] the check on a child's normal peak measures memory it really holds, and a test proves that the check fires
- [x] a signal to `tools/ci-local.sh` ends a running test step and leaves nothing behind, and the `bounds` job checks that with a real signal
- [x] the `bounds` job passes under a lower limit, and can't pass without seeing that the process it checks has ended
- [x] a step's failure says it timed out only after a real timeout
- [x] the instruction counts and the consumer smoke have a timeout

## Why

Compat mode can read a document with a byte order mark at the start of a later line and
return only part of its text, with no error. Default mode rejects these inputs, and a reader
of one document must not lose content silently.

## Acceptance criteria

- [x] in compat mode, a byte order mark at the start of a line never drops text: the input is rejected or its text is kept
- [x] compat treats that mark the same way whether or not the line holds a comment or a colon
- [x] default mode's rejection stays as it is
- [x] the changelog names the changed behavior

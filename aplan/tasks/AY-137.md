## Why

`crates/ayaml-bench/benches/throughput.rs` currently benchmarks only one 20 KB
file across six layers plus nine small synthetic shapes. It omits typed struct
decoding, borrowed strings, `SpannedTree` and `LineIndex`, `to_string` Serde
serialization, flow emission, multi-document streaming, the 4 KiB tree-versus-
stream boundary, scaling curves, and error-path latency.

## Acceptance criteria

- [x] `crates/ayaml-bench` consumes `ayaml-fixtures` across modular groups covering domain workloads, pipeline layers, the 4 KiB strategy boundary, scaling sizes, emission and serialization styles, `SpannedTree` and `LineIndex`, and error/rejection paths
- [x] a pre-timing semantic validation step verifies each measured read/emit path produces expected values before timing begins
- [x] `cargo bench --locked -p ayaml-bench --no-run` and a fast validation test pass in CI

## Why

Floats don't hash by value, so float-keyed mappings don't get the distribution a
hash map relies on. Hashing by value fixes that without changing equality.

## Acceptance criteria

- [ ] floats hash by value, with NaN and signed zero normalized so `Eq` and `Hash` agree
- [ ] integers and floats stay distinct, `NaN` equals `NaN`, and `0.0` equals `-0.0`, with tests
- [ ] the bucket-pinning test is replaced by an Eq/Hash consistency test
- [ ] a scaling test covers many float keys on the value and typed paths

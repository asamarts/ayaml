## Why

The default input limit admits 32 MiB, but max_events, max_collection_entries, max_anchors, and max_alias_dereferences refuse valid 0.3 to 7 MB documents. A caller switching to ayaml cannot rely on the input limit alone.

## Acceptance criteria

- [x] choose and document a default count profile that admits every valid document within max_input_bytes, or state and test the intended lower profile
- [x] cover the four reproduced shapes in the tests
- [x] keep limits fail-closed and do not weaken lower strict profiles

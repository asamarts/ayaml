## Why

The root parser reports where a malformed flow collection failed but omits
where that collection began. Aplan's existing CLI diagnostic includes both
locations, and ayaml already computes the opening context for compatibility
errors.

## Acceptance criteria

- [ ] malformed flow sequences and mappings report the failure and relevant opening locations
- [ ] the primary span remains the failure location
- [ ] nested flow forms, quoted delimiters, CRLF, BOM, and multibyte UTF-8 have regression tests
- [ ] default and compatibility modes retain their separate semantic profiles

## Why

Typed `from_str::<Value>` runs so close to its quiet-host performance target that the release's
measurement could fail on run-to-run noise alone. AY-021 and the other 0.1.2 fixes change the
typed path before then. This task follows AY-021, so that it measures the code the release
ships, and comes before AY-005.

## Acceptance criteria

- [ ] typed `from_str::<Value>`, in default and compat mode, has enough headroom against its target that run-to-run noise can't fail the release's measurement
- [ ] what it reads, and every error, is unchanged: the corpus comparison, conformance in both modes, the adversarial tests, and a fuzz smoke all agree with the commit before
- [ ] the other performance gates still pass

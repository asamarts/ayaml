## Why

Source comments, rustdoc, and tests name another parser and carry finding IDs
that point at documents readers cannot see, and tests use it as a dev-dependency.
Comparison with other parsers belongs outside this repository.

## Acceptance criteria

- [x] rustdoc and comments state each behavior on its own terms; libyaml is the only named reference, for what compat imitates
- [x] comparison assertions become literal expected values here, and the comparison checks themselves move to the maintainers' pre-release gates
- [x] the dev-dependency leaves the manifest and lockfile
- [x] finding IDs leave source and tests
- [x] the leak gate rejects the comparison names and the finding-ID forms that are in use from then on

## Why

Source comments, rustdoc, and tests name another parser and carry finding IDs
that point at documents readers cannot see, and tests use it as a dev-dependency.
Comparison with other parsers belongs outside this repository.

## Acceptance criteria

- [ ] rustdoc and comments state each behavior on its own terms; libyaml is the only named reference, for what compat imitates
- [ ] differential test assertions become literal expected values, with no coverage lost
- [ ] the dev-dependency leaves the manifest and lockfile
- [ ] finding IDs leave source and tests
- [ ] the leak gate enforces both from then on

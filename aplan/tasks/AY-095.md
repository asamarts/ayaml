## Why

Issue #163: the typed path reserved events from an estimate that was short on nested documents,
so the vector grew to about twice the events that fit while the token arena was still live.

## Acceptance criteria

- [x] event capacity is based on the token count plus headroom
- [x] a short estimate still grows by half rather than doubling
- [x] the 1 MB nested typed workload peak falls from about 64.8 MB to 49.4 MB
- [x] limits, event order, and the eager event APIs are unchanged

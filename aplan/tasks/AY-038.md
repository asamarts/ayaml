## Why

Public CI tests only with all features, runs rustdoc without denying warnings,
and collects an unsafe census that nothing evaluates. The local gate skips the
census without failing. There is no scheduled advisory scan, and the nightly
fuzz workflow is the only scheduled fuzzing, so a missed run would go unseen.

## Acceptance criteria

- [x] default-feature tests run in CI
- [x] rustdoc runs with `-D warnings`
- [x] the census result is evaluated, and a missing tool fails release runs rather than skipping
- [x] a scheduled advisory scan runs on public
- [x] a failed or missing scheduled fuzz run is noticed
- [x] runner-image and action-runtime deprecation warnings are resolved

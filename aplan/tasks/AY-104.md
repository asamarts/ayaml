## Why

Issue #178: short-scalar documents still peak above the 1.2x target because typed decoding builds
a complete `Node` tree and then builds the target value while the tree is still live. The token
arena also holds every token for the whole input.

## Current state

The token is 32 bytes and an untagged typed node is 80 bytes. Root flow collections reserve their
entry count. Current 1 MB peaks are about 98 MB for a flow sequence of `1`, 169 MB for an integer
flow sequence, 82 MB for a flow mapping, and 56 MB for a short-word block sequence. The reference
peaks are 67.8 MB, 34.3 MB, 35.7 MB, and 18.1 MB for the issue's shapes.

## Acceptance criteria

- [ ] untyped serde seeds can consume events or values without retaining a complete typed node tree
- [ ] duplicate keys, tags, aliases, limits, and typed error paths keep their current behavior
- [ ] the 1 MB flow sequence of `1` peaks within 1.2x of the libyaml reference, and the other #178 shapes meet the same target or have a documented exception
- [ ] typed allocation budgets are tightened and both test modes plus conformance pass
- [ ] the issue's generators or equivalent shapes are recorded with the measurements

## Why

Issues #132, #146, and #147 show block scalar headers accepted below their parent after anchor/tag properties, and a document marker after indented empty lines read as scalar content. Both readers are affected in different combinations.

## Acceptance criteria

- [x] a block scalar header after properties alone on its line is indented past its parent in both modes
- [x] a top-level block scalar with indented empty lines ends before a document marker and leaves an empty scalar
- [x] compat matches libyaml where it is intentionally different, with a documented deviation if needed

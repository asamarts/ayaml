## Why

Serializing a very deeply nested Rust value recurses before any depth check, so it
can abort the process instead of returning an error. It takes a deep Rust value,
not parsed input.

## Acceptance criteria

- [x] deep values return a depth error on a 2 MiB thread for `to_string`, `to_writer`, and `to_value`
- [x] the check runs before recursion can exhaust the stack, with a test at and above the limit
- [x] normal serialization performance is unaffected

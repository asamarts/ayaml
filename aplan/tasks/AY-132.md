## Why

The fuzz workspace currently has only three raw-byte targets (`parse`, `emit`,
`borrowed`). Raw byte mutations rarely reach deep valid structures, and newer
public surfaces (`SpannedTree`, `LineIndex`, `Value::apply_merge_keys`,
`Error::masked()`, arbitrary `Event` emission, and tree-versus-event-stream typed
equivalence) have no dedicated fuzz targets.

## Acceptance criteria

- [x] fuzz workspace adds structure-aware `arbitrary::Arbitrary` input generation for nested YAML documents, values, and event streams
- [x] dedicated fuzz targets cover structured YAML parsing/round-trips, `SpannedTree` and `LineIndex` invariants, `apply_merge_keys`, `Error::masked()` non-leakage, arbitrary `Event` emission, and tree-versus-stream typed equivalence
- [x] all targets compile in CI, run locally under `-rss_limit_mb=2048` with zero crashes, and are wired into `.github/workflows/fuzz.yml`
- [x] unit tests exercise the target harnesses deterministically on seed inputs so `cargo test` covers the harness logic

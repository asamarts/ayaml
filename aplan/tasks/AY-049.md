## Why

A tool that fixes a value needs that value's byte span. `Value` has no spans and events
have no paths, so consumers carry a second YAML parser to get them.

## Acceptance criteria

- [x] a read-only API gives the byte span of the value at a path, and the span to remove for an entry
- [x] a scalar-encoding function returns text that parses back to the same value in that position
- [x] paths use the existing `PathSegment`, and spans are byte ranges in the original source, byte-order mark included
- [x] aliases, merge keys, duplicate keys, and multiple documents give `None` rather than a guess
- [x] the normal limits apply
- [x] tests cover plain, quoted, block, and flow values, CRLF, a byte-order mark, and multibyte text

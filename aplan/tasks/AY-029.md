## Why

The published crate pins exact runtime versions, which breaks resolution for anyone
needing another version and makes security patches wait for an ayaml release. Its compat module is missing
from docs.rs, `cargo test` from the `.crate` does not compile, and the package has
no changelog.

## Acceptance criteria

- [ ] `serde` and `indexmap` use caret requirements at the lowest versions the full suite passes on, proven by the minimal-versions job
- [ ] docs.rs builds `ayaml::compat`, with feature labels in rustdoc
- [ ] `cargo test` works from the unpacked `.crate`, and a CI job proves it
- [ ] `CHANGELOG.md` is in the package
- [ ] the package-contents check covers all of this

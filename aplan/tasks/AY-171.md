## Why

Before running the `AY-150` 24+ core-hour pre-1.0 fuzz soak and release qualification, the
verification audit identified concrete coverage blind spots that would leave major post-0.2.3
and core code paths unverified during the soak:

1. **5 dead scenarios in `masked_errors` fuzz target:** `fuzz/src/arbitrary_yaml.rs` generates
   `scenario` in `0..=19` while `fuzz/src/lib.rs` dispatches `scenario % 25`, leaving scenarios
   20 through 24 (`from_reader`, `parse_frontmatter`, `DocumentDeserializer`,
   `ParseOptions::with_merge_keys(true)`, and `Spanned<String>`) at 0% execution.
2. **Fuzzing corpus, dictionary, and entry-point gaps:** No `fuzz/yaml.dict` exists; 7 of 10
   targets have no tracked seed corpus; `tools/fuzz-hosted.sh` does not pass an explicit
   `-rss_limit_mb=2048`; raw-byte `parse` never exercises `from_slice`, `from_reader`,
   frontmatter, merge keys, `DocumentDeserializer`, or `compat`; `edit` never checks
   `apply_batch` semantic mutations or arbitrary `apply_edits` slices; `merge_keys` never
   feeds raw bytes or compares across deserialization APIs; `typed_equiv` omits `Spanned<T>`;
   and `emit` omits Serde `to_string`/`to_writer` and `EmitOptions::flow()`.
3. **Adversarial DoS test gaps:** `crates/ayaml/tests/adversarial.rs` omits `from_reader_with`,
   `DocumentDeserializer`, `parse_frontmatter*`, `from_str_with(..., merge_keys(true))`,
   `Spanned<T>`, `Error::masked()` on large hostile errors, emitter escape/`%TAG` expansion,
   and `ayaml-edit` hostile inputs.
4. **Mutation-testing scope and silent warnings:** `.github/workflows/mutants.yml` currently
   mutates only 5 files of `ayaml` (0 of `ayaml-edit`) and converts exit codes 2 (missed
   mutants) and 3 (timeouts) into warnings with exit 0, hiding regressions from
   `scheduled-watch.yml`.
5. **Narrow Kani proofs and Miri coverage:** `position.rs`'s `to_offset` Kani proof runs on a
   13-byte input (constant-folding past the 256-byte chunk loop), `error.rs`'s quoted-key
   proof checks only 3 concrete strings, `frontmatter.rs`'s proof covers only 2-byte UTF-8, and
   `miri.yml` does not exercise `spanned`, `masked_errors`, `error_codes`, `state_machines`,
   or `--cfg ayaml_typed_from_events`.

## Scope

1. **Fix `masked_errors` dead scenarios and harden fuzzing (`fuzz/`, `tools/fuzz-hosted.sh`):**
   - Fix `0_u8..=19` -> `0_u8..=24` in `fuzz/src/arbitrary_yaml.rs` and add a unit test in
     `fuzz/src/lib.rs` proving every `masked_errors` scenario branch executes.
   - Add `fuzz/yaml.dict` covering YAML 1.2.2 tokens, directives, tags, escapes, and merge keys,
     plus minimal tracked seed corpora for all 10 targets.
   - Pass `-rss_limit_mb=2048` and `-dict=fuzz/yaml.dict` in `tools/fuzz-hosted.sh`.
   - Expand `parse`, `merge_keys`, `edit`, `typed_equiv`, and `emit` fuzz harnesses to cover all
     public post-0.2.3 entry points, `apply_batch` result verification, `apply_edits`,
     `Spanned<T>`, and Serde/flow emission.
2. **Expand process-isolated adversarial coverage:**
   - Add `in_child!` adversarial tests for post-0.2.3 APIs, `Error::masked()` on large errors,
     emitter escape/`%TAG` expansion, and hostile `ayaml-edit` inputs/batches.
3. **Expand mutation testing and fail on unexpected survivors:**
   - Extend `.github/workflows/mutants.yml` to cover `frontmatter.rs`, `merge.rs`,
     `merge/events.rs`, `error.rs`, `resolver.rs`, `composer.rs`, `number.rs`, and
     `crates/ayaml-edit/src/lib.rs` alongside the existing 5 modules, adjust `.cargo/mutants.toml`
     so relevant integration tests kill mutants cleanly, and make exit code 2 fail the job.
4. **Strengthen Kani proofs and Miri suites:**
   - Upgrade `position.rs`, `error.rs`, and `frontmatter.rs` Kani harnesses (within `tools/run_kani.py`
     memory/time ceilings) to exercise the 256-byte chunk loop, symbolic byte patterns, and
     3-/4-byte UTF-8 characters.
   - Add bounded small-input Miri runs in `.github/workflows/miri.yml` for `spanned`,
     `masked_errors`, `error_codes`, `state_machines`, and `--cfg ayaml_typed_from_events`.

## Acceptance criteria

- [ ] all 25 `masked_errors` scenarios are reachable and verified by `cargo test --manifest-path fuzz/Cargo.toml --lib --locked`
- [ ] all 10 fuzz targets compile, have tracked seeds + `fuzz/yaml.dict`, and pass bounded smoke runs with `-rss_limit_mb=2048`
- [ ] expanded `adversarial.rs` and `ayaml-edit` adversarial tests pass in debug and release builds
- [ ] `python3 tools/run_kani.py --package ayaml --all-features` and `ayaml-edit` pass within memory/time budgets with the strengthened proofs
- [ ] `miri.yml` and `mutants.yml` updates pass CI policy checks and local bounded verification
